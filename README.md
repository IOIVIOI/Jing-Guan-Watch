# 静观 · AI Agent 健康手表

面向活力老人的禅意中式 AI 健康手表交互原型。手表主界面只保留月夜轻舟视觉，用户通过右侧实体键唤醒语音助手，以自然语言查看健康数据、调整推荐和设置日常提醒。

## 使用

直接用浏览器打开 `index.html`。

- 点击手表右侧实体键开始聆听，再次点击结束并执行。
- 浏览器支持语音识别时会读取麦克风；否则可以在唤醒态的输入框中输入演示指令。
- 说“你能做什么”可以打开可点击的指令示例面板。
- 完整演示指令见 `演示指令清单.md`。

## 文件

- `index.html`：页面结构
- `styles.css`：禅意玻璃界面与语音动效
- `app.js`：指令解析、界面状态和操作执行
- `data.js`：虚构健康数据
- `assets/`：由主视觉裁切生成的桌面与移动端素材
- `外观与界面设计参考/`：设计参考图与动效
